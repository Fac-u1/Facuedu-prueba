Extensiones para el Navegadore

Qué son, dónde buscarlas y cómo instalarlas con seguridad.

¿Qué es una extensión?

🧩 Una extensión es un complemento pequeño que le agrega funciones nuevas al navegador. Es como sumarle una herramienta extra a tu mochila.

Compatibilidad

Tienda¿Funciona en el Navegadore?
Chrome Web Store✅ Puede funcionar, no todas
Edge Add-ons✅ Puede funcionar, no todas
Opera GX✅ Puede funcionar, no todas
Firefox❌ No funciona

El Navegadore usa Electron, que soporta solo una parte de la API de extensiones de Chrome. Por eso algunas extensiones pueden no andar.

Cómo instalar desde una carpeta

  1. 1Descargá la extensión desde la tienda.
  2. 2Descomprimí el archivo en una carpeta (debe tener un archivo manifest.json).
  3. 3En el Navegadore, abrí el ícono de rompecabezas y elegí "Instalar desde una carpeta".
  4. 4Elegí la carpeta descomprimida.

Podés activar, desactivar o quitar extensiones desde el mismo panel.
